# 📐 線性規劃｜互動學習網

依據教材〈第 1 章 線性規劃〉（平行直線系、二元一次不等式、線性規劃）製作的互動學習網站，支援手機、平板與電腦。純 HTML／CSS／JavaScript，不需安裝任何套件，也不依賴外部 CDN，可離線使用。

## 🚀 使用方式

- **直接開啟**：下載後用瀏覽器開啟 `index.html`。
- **GitHub Pages**：到 repository 的 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main`／`(root)`，儲存後約 1 分鐘即可透過 `https://<帳號>.github.io/<repo>/` 瀏覽。

## 📁 檔案架構

```
.
├── index.html                    # 首頁（單頁式網站）
├── .nojekyll                     # 讓 GitHub Pages 直接提供靜態檔案
├── README.md
└── assets/
    ├── css/
    │   └── style.css             # 版面、亮色／暗色主題、字體大小、裝置模擬
    ├── js/
    │   ├── plot.js               # SVG 繪圖引擎：直線、半平面、可行解區域、頂點、最佳解
    │   ├── data.js               # 教材內容：課程、例題／隨堂練習／習題、測驗題庫、中英文字
    │   └── app.js                # 主程式：導覽、實驗室、練習、測驗、學習歷程、設定、音效
    └── pdf/
        └── linear-programming.pdf  # 原始教材 PDF（可於網站中下載）
```

### ⚙️ 顯示與操作設定（右上角齒輪）

全螢幕（開／關）、音效（開／關）、裝置（自動／手機／平板／電腦）、版面（自動／直式／橫式）、語言（繁體中文／English）、字體（縮小／標準／放大）、色系（跟隨系統／亮色／暗色）。設定會儲存在瀏覽器中。

## 🔒 資料與隱私

學習紀錄只存在使用者自己瀏覽器的 `localStorage`（鍵名前綴 `lp3.`），不會上傳到任何伺服器。可在「學習歷程」頁下載或清除。
